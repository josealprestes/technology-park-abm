Fontes da interface e o catálogo científico estão em [prototypes/](prototypes/).
As onze opções compreendem nove configurações numéricas originais, uma
variante de capacidade e uma configuração didática de massa crítica. Os
dossiês declaram classe de evidência e nível de acesso; uma aplicação
publicada da literatura não valida este modelo.

HTML gerado, resultados e dados brutos não são versionados. Reconstrua com
o guia de operação. Sincronizar o Git não cria release.
